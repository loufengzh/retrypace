# Security

retrypace reads a local JSON file and computes schedules. It makes no network requests and executes no commands from configuration. Input is bounded, but large valid reports can consume significant CPU, memory and disk space. Treat configurations from untrusted sources cautiously and run with operating-system resource limits where appropriate.

Do not put credentials, production request bodies or personal information in scenarios or public issues. For a vulnerability, use the repository's private vulnerability-reporting option if available. If unavailable, open an issue asking for a private contact without exploit details or secrets. No response-time guarantee is currently offered.
